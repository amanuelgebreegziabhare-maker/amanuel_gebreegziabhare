# Grocery Inventory Dashboard

## Project Overview

This Power BI dashboard provides inventory management insights for grocery retail operations. It visualizes stock levels, product availability, and turnover metrics to support inventory planning and supplier performance monitoring.
## Screenshot

![Grocery Inventory Dashboard](Grocery%20Inventory%20Dashboard%20Screenshot.png)

## Objectives

- Measure stock levels and product availability
- Analyze stock movement and inventory turnover
- Identify high- and low-performing products
- Support replenishment decisions and supplier management

## Tools & Techniques

- Power BI Desktop
- Power Query for data transformation
- DAX for inventory calculations and metrics
- Dashboard design for retail inventory managers

## Files Included

- `Inventory Dashboard.pbix` — Power BI report file
- `Grocery_Inventory.csv` — source inventory dataset
- `Grocery_Inventory new v1-selected-columns.csv` — filtered dataset used for the dashboard
- `Grocery Inventory Dashboard Screenshot.png` — report preview
- `Grocery Inventory Dashboard Background-02.png` — dashboard background asset
- `Grocery Logo.png` — branding logo


## Key Metrics

- Total stock quantity
- Stock value by category
- Average turnover ratio
- Supplier performance and product life cycle

## How to Explore

Open `Inventory Dashboard.pbix` in Power BI Desktop to review the visual pages, dynamic filters, and inventory analytics. The dashboard is built to help grocery store managers reduce stockouts and optimize inventory levels.
