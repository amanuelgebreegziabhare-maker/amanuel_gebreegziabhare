# Finance Analysis Project

## Project Overview

This Power BI project delivers a comprehensive Finance Analysis dashboard designed to provide real-time insights into financial transactions, customer behavior, revenue performance, taxes, fees, and business risks. The report enables stakeholders to monitor financial health, evaluate transaction trends, and identify opportunities for data-driven decision-making.

## Dashboard Insights

### Overview Analysis

The dashboard provides executive-level visibility into:

- Monthly financial performance trends
- Customer segment contribution
- Transaction success, failure, and pending rates
- Revenue distribution across states
- Gender-based financial activity analysis
- Financial fee and tax performance

### Transaction Drill-through Analysis

The transaction-level page enables users to:

- Explore detailed transaction records
- Analyze transaction types and status
- Filter by year, occupation, category, and dynamic metrics
- Investigate customer-level transaction activity
- Monitor transactional risks and anomalies

---

## How to Explore

1. Open `Power BI Project - Finance Analysis Complete Dashboard.pbix` in Power BI Desktop.
2. Use the slicers to filter by:
   - Year
   - Dynamic Metric
   - Occupation
   - Category
3. Navigate between the Overview Analysis and Transactions pages.
4. Use drill-through functionality to investigate detailed transaction data.
5. Analyze KPIs, trends, and customer insights using the interactive visuals.
