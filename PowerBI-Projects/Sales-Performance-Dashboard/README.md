# Sales Performance Dashboard

## Project Overview

This Power BI project showcases a high-impact sales performance dashboard for business stakeholders. It brings together multiple sales datasets to analyze revenue, product performance, regional trends, and forecasted targets.

## Objectives

- Monitor sales performance across regions and products
- Identify top-selling products and underperforming categories
- Track revenue and growth against targets
- Provide actionable insights for sales strategy

## Tools & Techniques

- Power BI Desktop
- Power Query for ETL and data transformation
- DAX for measures and KPIs
- Star schema data modeling
- Interactive reports and bookmarks

## Key Features

- Revenue and volume overview cards
- Trend analysis by month and region
- Product category and segment comparisons
- Top customer and channel performance
- Drill-through and filter interactions

## Data Sources

- Sales transaction data
- Customer and product master tables
- Regional and timeframe lookup tables

## Insights Delivered

- Sales growth patterns across key markets
- Product categories driving the highest revenue
- Performance gaps between regions and channels
- Recommendations for focus areas and improvements

## Files Included

- `Sales-Performance-Dashboard.pbix` — Power BI report file
- `data/` — Source datasets used for analysis
