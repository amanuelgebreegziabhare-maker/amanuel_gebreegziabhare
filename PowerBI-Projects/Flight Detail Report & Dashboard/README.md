# Flight Detail Report & Dashboard

## Project Overview

This Power BI solution includes a flight operations dashboard and a finance analysis dashboard. It provides detailed visibility into flight delays, cancellations, transaction activity, and customer financial behavior.

## Objectives

- Track flight performance and delay trends
- Analyze cancellations by airline and reason
- Monitor financial transactions and customer spending
- Reveal operational and revenue insights for airlines

## Tools & Techniques

- Power BI Desktop
- Power Query for data preparation
- DAX for time intelligence and aggregated metrics
- Storytelling visuals for flight operations and finance analysis

## Key Metrics

- Total flights, delayed flights, and cancellations
- Percentage delayed by airline and city
- Total transaction amount and average transaction value
- Customer segment revenue and transaction status

## How to Explore

Open the Power BI report files in Power BI Desktop to explore both the flight operations and finance analysis dashboards. Use slicers and filters to inspect performance by airline, status, and date.
