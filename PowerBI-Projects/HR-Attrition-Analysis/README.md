# HR Attrition Analysis

## Project Overview

This Power BI report explores employee attrition and retention trends for HR leaders. It analyzes workforce data to identify drivers of turnover, assess risk factors, and highlight opportunities for employee engagement.

## Objectives

- Measure attrition rates by department and location
- Identify factors influencing employee turnover
- Visualize employee demographics and satisfaction metrics
- Support HR decisions with data-driven insights

## Tools & Techniques

- Power BI Desktop
- Power Query for cleaning and shaping HR data
- DAX for attrition rate calculations and cohort metrics
- Interactive dashboard design for HR stakeholders

## Key Features

- Attrition rate trends over time
- Breakdown by department, job role, and tenure
- Employee satisfaction and performance views
- Risk indicators for high-turnover groups
- Scenario filters for workforce planning

## Data Sources

- Employee records and demographics
- Job role and department information
- Performance and survey data
- Attrition and termination history

## Insights Delivered

- Departments and job roles with the highest attrition
- Correlation between tenure, satisfaction, and retention
- High-risk segments that need targeted intervention
- Recommendations for HR retention strategies

## Files Included

- `HR-Attrition-Analysis.pbix` — Power BI report file
- `data/` — HR datasets and supporting files
- `README.md` — Project documentation

## How to Explore

Open the Power BI file in Power BI Desktop to review the dashboards, drill into employee segments, and analyze the attrition story. Use the report filters to inspect workforce dynamics and risk indicators.
