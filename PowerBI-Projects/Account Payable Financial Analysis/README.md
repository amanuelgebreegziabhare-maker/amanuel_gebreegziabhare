# Account Payable Financial Analysis

## Project Overview

This Power BI project delivers an Accounts Payable dashboard designed to help finance teams monitor payables, vendor performance, and cash outflow risk. The report uses transactional and vendor data to reveal overdue payables, payment status, and invoice trends.


## Screenshot

![Accounts Payable Dashboard](Accounts%20Payable%20Dashboard%20-%20Screenshot.png)


## Objectives

- Track outstanding payables by vendor and currency
- Identify invoices by status and due date bands
- Monitor cash flow exposure in accounts payable
- Support vendor payment prioritization and risk management

## Tools & Techniques

- Power BI Desktop
- Power Query for data import and transformation
- DAX for measures and analytics
- Report design for finance stakeholders

## Files Included

- `Financial Dashboard.pbix` — Power BI report file
- `Accounts Payable Dashboard - Screenshot.png` — dashboard preview
- `Power BI AP DAX YouTube Script.docx` — DAX and storytelling notes for the report


## Key Metrics

- Total payable amount
- Outstanding amount by currency
- Invoice amount by status
- Vendor risk and overdue analysis

## How to Explore

Open `Financial Dashboard.pbix` in Power BI Desktop to review the dashboard pages, slicers, and visual insights. The report is built for finance users who need fast visibility into payables and vendor performance.
