What to include in each project `README.md`:

- Project title and short summary
- Tools used (Power BI Desktop, DAX, Power Query, SQL, Python)
- Data sources and size/refresh notes
- Key data model details (fact & dimension tables, relationships)
- Important DAX measures (show code snippets and purpose)
- Performance tuning steps (aggregations, query folding, incremental refresh)
- Screenshots and a link to an interactive report (if published)
- Business impact / results (quantify when possible)
